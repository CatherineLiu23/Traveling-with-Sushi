# Traveling-with-Sushi
一个以苏轼为核心的历史文化互动游戏。
与其阅读苏轼，不如去见苏轼。

　　项目简介

　　《旅行苏轼》是一款基于 Python + Pygame 开发的历史文化互动游戏。

　　玩家将以一个现代人的身份进入一个介于现实与历史之间的空间，并与青年时期的苏轼相遇。

　　你可以：

　　• 在苏轼的草庐中探索
　　• 进入苏轼的人生地图，前往不同地点
　　• 在眉州与青年苏轼交流
　　• 观察并触发历史场景与物品故事
　　• 与苏轼进行 AI 对话
　　• 与苏轼进行诗词唱和
　　• 接收来自苏轼的书信
　　• 收集旅行途中获得的物品与诗稿
　　• 逐渐了解苏轼的性格、经历与文学世界

　　项目希望尝试回答一个问题：

　　如果历史人物不再只是书本上的名字，而是一个可以与你交谈、写信、作诗的人，会发生什么？

　　⸻

　　 核心特色

　　1. 与苏轼对话

　　游戏使用大语言模型构建苏轼的交互式人格。

　　目前眉州场景中的苏轼被设定为嘉祐元年前后的青年苏轼：

　　• 字子瞻
　　• 眉州眉山人
　　• 与父亲苏洵、弟弟苏辙准备赴京赶考
　　• 具有青年时期的知识范围与身份背景
　　• 不应知道宋代以后出现的历史与技术知识
　　• 根据玩家的对话内容进行回应

　　AI 并非简单地使用一个人物提示词，而是加入了动态语料检索机制：

　　1. 获取玩家当前输入
　　2. 根据关键词从人物语料库中寻找相关材料
　　3. 将相关历史/文学材料动态加入 System Prompt
　　4. 再调用大语言模型生成回复

　　这样可以让不同话题触发不同的苏轼记忆与语言素材。

　　⸻

　　2. 历史场景探索

　　游戏目前采用 Pygame 构建多个可切换场景。

　　基本流程：

　　草庐大厅
　　   │
　　   ├── 左侧：现实出口
　　   │
　　   └── 右侧：苏轼人生
　　             │
　　             ▼
　　          人生地图
　　             │
　　             ▼
　　            眉州

　　目前已经实现：

　　• 草庐 / Lobby
　　• 苏轼人生地图
　　• 眉州场景

　　地图系统为后续扩展其他历史地点预留了空间。

　　⸻

　　3. 场景中的历史物件

　　在眉州场景中，玩家可以与场景中的物品互动。

　　例如：

　　• 奇石 / 砚台
　　• 书籍

　　点击物品后，会触发对应的历史情境与对话。

　　这种设计希望让历史信息不再以“弹窗百科”的形式出现，而是通过物件 → 故事 → 人物的方式自然呈现。

　　⸻

　　4. 诗词唱和

　　游戏中包含一个独立的诗词唱和系统。

　　玩家可以向苏轼提交自己的诗作。

　　系统首先会进行基础押韵检测：

　　玩家诗作
　　   ↓
　　提取各句末字
　　   ↓
　　查询韵书
　　   ↓
　　检查是否同韵
　　   ↓
　　通过
　　   ↓
　　苏轼 AI 评价 / 唱和

　　目前使用 prompts/rhymes.json 作为韵书数据，并通过 RhymeChecker 完成基础检测。

　　通过押韵检查后，诗稿还会被作为游戏物品保存。

　　因此玩家写下的诗并不会只是一次性的输入，而会成为自己在游戏中的旅行遗物。

　　⸻

　　5. 书信系统

　　游戏包含一个动态书信系统。

　　随着游戏时间与玩家进度推进，玩家有机会收到来自苏轼等角色的书信。

　　书信可以：

　　• 推进人物关系
　　• 补充历史背景
　　• 提供旅行中的叙事内容
　　• 赠送特殊物品

　　部分信件还会根据玩家名字进行动态替换。

　　例如：

　　{player_name}

　　会被替换为玩家在游戏开始时输入的名字。

　　⸻

　　 AI 系统

　　AI 相关逻辑主要位于：

　　ai_handler.py

　　核心函数：

　　ask_ai()

　　它负责：

　　1. 接收人物设定
　　2. 分析玩家当前输入
　　3. 从人物语料库中选择相关内容
　　4. 构造动态 System Prompt
　　5. 调用大语言模型 API
　　6. 返回人物回复

　　人物设定

　　人物资料主要存放于：

　　prompts/
　　└── ss_meizhou.json

　　其中包括：

　　• 人物身份
　　• 世界观
　　• 性格
　　• 知识范围
　　• 兴趣
　　• 历史背景
　　• 旅行路线
　　• 人物语料

　　因此，人物设定与程序逻辑是相对分离的。

　　如果未来希望加入其他历史人物，可以考虑复用这一结构。

　　关于历史与游戏

　　《旅行苏轼》并不试图把历史人物完全还原成一个“百科全书式 NPC”。

　　游戏中的人物对话由：

　　历史资料 + 人物设定 + 文学语料 + AI 生成

　　共同构成。

　　因此，AI 的具体回答不应被视为严格的历史文献。

　　对于历史事实，应以可靠的历史文献与学术研究为准。

　　项目更希望提供的是一种新的历史体验：

　　历史不是一张已经凝固的照片。

　　当我们真正走近一个人时，
　　我们首先遇见的，或许不是他的“成就”，
　　而是一个会说话、会写信、会作诗、会与你一起旅行的人。
